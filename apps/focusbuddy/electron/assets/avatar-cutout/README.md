# Recortes transparentes del chibi oficial

Esta carpeta contiene copias derivadas de los doce PNG entregados por el equipo
de ilustración. Los originales permanecen intactos en `../avatar-official/`,
junto con su manifiesto de procedencia.

Los recortes se prepararon el 7 de octubre de 2026 con el editor de imágenes
integrado de OpenAI, usando cada PNG original como único objetivo de edición. El
cambio solicitado fue quitar exclusivamente el fondo gris `#B7B7B7`, producir
transparencia real y conservar pose, expresión, proporciones, línea, colores y
detalles. No se pidió añadir objetos, texto, sombras ni un estilo nuevo.

Las copias mantienen un lienzo cuadrado y margen transparente para que los
fotogramas compartan un punto de apoyo estable durante la animación. FocusBuddy
consume estas versiones; nunca sobrescribe las ilustraciones fuente.

Si el equipo de ilustración entrega exportaciones originales con canal alfa,
esas exportaciones deben reemplazar estos derivados manteniendo los mismos
nombres de archivo.

# Avatar oficial de FocusBuddy

Estos archivos fueron descargados el 7 de octubre de 2026 desde la carpeta
compartida `Fase 2/Evidencias de Proyectos/Avances del Avatar (pintados)` del
Drive del equipo. Los nombres locales fueron normalizados para usarlos de forma
segura como fuentes preservadas y para mantener la correspondencia con los
derivados de runtime; los originales del Drive no fueron modificados.

Estas ilustraciones fuente no se consumen directamente en runtime. Cada imagen
mide 2136 x 2136 píxeles y conserva el fondo opaco `#B7B7B7` recibido. La
aplicación utiliza copias derivadas con transparencia desde
`../avatar-cutout/`, sin sobrescribir los originales de esta carpeta. Cuando el
equipo de ilustración entregue exportaciones fuente con canal alfa, podrán
reemplazar esos derivados conservando los mismos nombres.

El vínculo de procedencia, el identificador de Drive y el nombre original de
cada archivo están registrados en `source-manifest.json`.
